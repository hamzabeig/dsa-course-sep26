# 🚀 6-Week DSA Problem Solving Bootcamp

A 6-week **Data Structures & Algorithms (DSA)** learning and problem-solving session based on the **NeetCode 150** roadmap.

The goal is not just to solve problems, but to understand the **data structures, algorithms, problem-solving patterns, complexity analysis, and techniques** required to solve DSA problems independently.

## 📚 Course Overview

| | Details |
|---|---|
| 💻 Problem Source | [NeetCode 150](https://neetcode.io/practice/practice/neetcode150) |
| 🧩 Problems we will solve | ~90 Problems |
| 📈 Focus | Concepts + Patterns + Problem Solving |

---

# 🎯 Course Objectives

By the end of the 6 weeks, students should be able to:

- Understand fundamental data structures and algorithms
- Analyze **Time and Space Complexity**
- Identify common DSA problem-solving patterns
- Approach problems using **Brute Force → Optimization**
- Implement solutions efficiently
- Recognize which data structure or algorithm fits a problem
- Solve common **LeetCode/NeetCode-style interview problems**
- Develop independent problem-solving skills

---

# 🧠 Teaching Methodology

The sessions will follow this general approach:

```text
Concept
   ↓
Understand the Data Structure / Algorithm
   ↓
Brute Force Approach
   ↓
Identify the Problem Pattern
   ↓
Optimize the Approach
   ↓
Implement the Solution
   ↓
Analyze Time & Space Complexity
   ↓
Practice Related Problems
```

The main focus will be **understanding the pattern**, rather than memorizing individual solutions.

# ⏱️ Standard 1-Hour Session Structure

| Time | Activity |
|---|---|
| 0–5 min | Recap of previous session |
| 5–15 min | Concept / DSA basics |
| 15–30 min | Problem 1 – Teach + Solve |
| 30–45 min | Problem 2 – Guided Solving |
| 45–57 min | Problem 3 – Pattern/Application |
| 57–60 min | Complexity + Key Takeaways |

### 📝 First Day of a New Data Structure

When introducing a new data structure, more time will be spent on fundamentals:

```text
10–20 min → Data Structure Basics
20 min    → Problem 1
15 min    → Problem 2
5–10 min  → Problem 3 / Review
```

> **Note:** Three problems per session is an average. Difficult topics such as Graphs and Dynamic Programming may require more explanation and less emphasis on the number of problems completed.

# 🧩 Core Problem-Solving Framework

Every problem should be approached using:

### 1. Understand

- What is the input?
- What is the output?
- What are the constraints?
- What are the edge cases?

### 2. Brute Force

Ask:

> "What is the simplest solution I can think of?"

Then analyze its complexity.

### 3. Identify the Pattern

Ask:

> "Does this problem resemble a known DSA pattern?"

Common patterns:

- Hashing
- Two Pointers
- Sliding Window
- Stack
- Binary Search
- Fast & Slow Pointers
- DFS
- BFS
- Heap / Priority Queue
- Backtracking
- Dynamic Programming
- Greedy
- Intervals
- Union-Find
- Bit Manipulation

### 4. Optimize

Look for:

- Reduced time complexity
- Better data structures
- Avoiding repeated work
- Precomputation
- Space-time tradeoffs

### 5. Implement

Write clean and readable code.

### 6. Analyze

Always finish with:

```text
Time Complexity: O(?)
Space Complexity: O(?)
```

# 📌 Important Note About NeetCode 150

The **NeetCode 150** contains 150 problems.

This 6-week course intentionally covers approximately **90 problems** during live sessions.

The remaining problems can be used as **self-practice/homework**.

The objective is **not**:

> ❌ "Finish as many problems as possible."

The objective is:

> ✅ **Understand the concept → recognize the pattern → solve the problem independently.**

# 🏠 Recommended Homework

After each session, students should:

1. Re-solve the problems without watching the solution.
2. Attempt 1–2 additional problems from the same NeetCode category.
3. Write down the pattern used.
4. Record the time and space complexity.
5. Try to solve at least one problem without looking at previous code.
